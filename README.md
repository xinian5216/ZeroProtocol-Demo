# 零点协议：ZERO PROTOCOL — Windows Demo

昔年 XINIAN 的第一人称科幻潜入原型。个人主导设计、需求与验收，借助 AI 完成大量工程实现和资源制作。

本仓库只提供公开介绍与 Windows x64 二进制附件，游戏源码未公开。请下载 Releases 中的 `ZeroProtocol-v0.5.0-Windows-x64-public.zip`，GitHub 自动 Source code 包不是游戏程序。

`v0.5.0-prototype` 为可运行原型，非正式商业发行。完整解压后运行 ZeroProtocol.exe，保留 Data、Mono 和 DLL。WASD 移动，鼠标观察，Shift 奔跑，E 交互，Q 地面诱饵，Esc 释放鼠标，F1 音量，M 静音。

Windows 未签名程序可能提示未知发布者，请核对来源与 SHA256SUMS，按自己的安全策略决定是否运行；无需关闭系统保护。

归档时一次连续 131/131 Play Mode 通过，分发副本另经真实 Windows 诱饵路线、失败及重新开始验证。测试不代表没有 Bug 或全程稳定 60 FPS。有限场景，无战斗、复杂追击或多人；其他硬件兼容性与首次时长尚未全面验证。

公开 ZIP 只去除两个程序集 CodeView 调试记录中的本机构建路径，补齐说明和 Noto Sans SC 的 SIL OFL 许可；玩法代码和资源不变。请使用本公开 ZIP 自己的哈希。
